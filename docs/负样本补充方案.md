# 负样本补充方案

**状态：待选，确认采用后执行。**

## 目的

补充没有目标物品的真实场景，减少干净地面和正常环境被判为 FAIL 的情况。

## 样本类型与标注

| 类型 | 内容 |
|---|---|
| 空场景 | 没有杂物的空房间、地面、走廊，覆盖不同材质、光照、阴影和反光 |
| 正常场景 | 可以包含家具、门窗、桌腿、鞋子等其他物体，但没有五类目标 |

两类图片均标为 **PASS**：全画面没有罐、瓶、包装物、杯、纸类物品，五类计数为零，目标标注为空。

筛选范围是整张图片，不只是地面。纸杯归杯，纸袋和包装纸归包装物；正在使用的目标物品也按现有类别口径处理。

## 候选来源

| 来源 | 适合补充的内容 | 采用方式 |
|---|---|---|
| [Wikimedia：Vacant rooms](https://commons.wikimedia.org/wiki/Category:Vacant_rooms) | 无家具或物品的空房间、空地面 | 优先筛选真实照片，逐图保留作者、来源和许可 |
| [SUN RGB-D](https://rgbd.cs.princeton.edu/) | 包含正常家具等物体的室内场景 | 从 10335 张 RGB-D 图像中筛选，只使用 RGB 图片，并核对五类目标是否出现 |
| [Hugging Face：empty-room](https://huggingface.co/datasets/wunderkinds07/empty-room) | 空房间、空地面 | 备用来源，筛选 `Before_Image`；采用前确认图片来源与使用许可 |

这些是候选素材来源，筛选确认后的图片才进入正式 PASS 集合。

**优先组合：Wikimedia 空场景 + SUN RGB-D 正常场景。**

## 采用后的处理方式

1. 收集候选图片，记录原始来源、作者、许可和场景信息。
2. 逐图核对五类目标，保留明确符合条件的负样本，去除重复图片。
3. 转换成现有项目标注格式，复用 `ProjectDataset` 读取接口。
4. 按场景分组划分训练、验证和测试集；同一场景的相似图片放在同一集合。
5. 与原有目标图片联合训练，在验证集上选择阈值，用独立实测场景评价。

评价同时关注 **PASS 召回率**和 **FAIL 召回率**：既观察误报是否减少，也观察是否增加漏检。
